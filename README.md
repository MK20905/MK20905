<p>
  <img src="https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white" />
  <img src="https://img.shields.io/badge/Bioinformatics-2E8B57?style=flat-square" />

  <img src="https://img.shields.io/badge/FreeSASA-008080?style=flat-square" />
</p>

Built a benchmarking pipeline to compare **AlphaFold2 and ESMFold protein structure predictions** using multiple structural and confidence-based evaluation metrics.

Analyzed model performance through **pLDDT confidence scores, RMSD, solvent-accessible surface area (SASA), contact overlap, protein length, and structural clash analysis** to evaluate prediction quality across proteins.

**Repository:** [AlphaFold2-vs-ESMFold](https://github.com/MK20905/Alphafold2-vs-ESMFold)
